# Grupo REV - Sistema de Gestión Logística Multicanal

Aplicación de escritorio desarrollada en Python para la administración, control de inventario, trazabilidad de órdenes de venta (OV) y gestión de embarques en múltiples canales comerciales (VL, PEGE, TIAU, MUESTRAS, AMAZON, MH).

## 🚀 Características Principales
- **Control de Acceso Seguro:** Módulo de autenticación corporativa basado en roles.
- **Gestión Multicanal:** Bitácoras independientes y consolidadas en tiempo real.
- **Persistencia Local Robusta:** Integración nativa con bases de datos SQLite y normalización de datos mediante Pandas.
- **Automatización Documental:** Manejo de guías en formato PDF y exportación masiva a reportes de Excel (`.xlsx`).
- **Interfaz Moderna:** UI construida con CustomTkinter orientada a la experiencia de usuario de alta eficiencia.

## 🛠️ Tecnologías Utilizadas
- **Python 3.x**
- **CustomTkinter** (Interfaz gráfica avanzada)
- **SQLite3** (Gestión de base de datos relacional local)
- **Pandas & OpenPyXL** (Manipulación y exportación de datos tabulares)
